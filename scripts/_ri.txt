# doc_insert_table_rows

批量在表格不同位置插入多行（DOC）。通过 table_id 或 idx 定位表格（优先 table_id）。所有 anchor_row 基于**原始表格**（调用前的状态），调用方不需要跟踪插入后的行号漂移。handler 内部按 anchor_row 降序处理（先插下面的再插上面的），保证互不干扰。可选 cells 数组为新增行写入内容，用 (insert_index, row_offset, col) 定位，不依赖最终行号。每个插入点可设置 default_cell_format 作为默认样式，cells 中未指定的字段继承默认值，减少 token 消耗。

参数（✓=必填）：
  [✓] row_inserts (array<object>): 插入点数组。每个元素指定一个位置和数量。anchor_row 基于**原始表格**的行号。
  [ ] cells (array<object>): 可选：为新增行写入内容。每个 cell 用 (insert_index, row_offset, col) 定位。insert_index 对应 row_inserts 下标，row_offset 是相对于该插入点第一行新行的偏移。字段格式同 doc_set_table_cells 的 cells（text/text_format/property/horizontal_align）。
  [ ] file_id (string): The file_id of the editor to operate on
  [ ] idx (integer): 表格内任意 cell 的 DOC 坐标（table_id 未提供时使用）
  [ ] table_id (string): 表格唯一标识（8 字符字符串），优先使用。与 idx 二选一提供即可。
